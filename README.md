# EARTHIA Industries Co., Ltd.

福井・北陸を拠点とする清掃会社 EARTHIA Industries のコーポレートサイト。
ビルド不要の静的サイトで、GitHub Pages から配信します。

## 構成

```
index.html            サイト本体（HTML / CSS / JS を1ファイルに同梱）
images/               ヒーロースライド（slide1–4）とビフォーアフター写真（ba1–6）
favicon.svg           E モノグラムのファビコン
apple-touch-icon.png  iOS ホーム画面用（180px、SVG 非対応のため別途）
.nojekyll             GitHub Pages の Jekyll 処理を無効化
```

ヒーローの動画5本は Higgsfield CDN（CloudFront）から直接読み込むため、
リポジトリには含まれません。

## ページの中身

- **ヒーロー** — 画像4枚と動画5本を7秒ごとに切り替えるシネマ風シーケンス。
  締めはチーム集合の動画で、文字の焼き込みがない素材なので社名はオーバーレイだけが出ます。
  レターボックス、フィルムグレイン、Ken Burns、シーンごとのコピーを重ねています。
- **イントロ** — 「掃除文化を未来へ」のステートメント。
- **実績（ビフォーアフター）** — グリストラップ清掃6件。
  ハンドルをドラッグして施工前後を比較できます（マウス／タッチ対応）。

## 実装メモ

- **モバイルの動画 autoplay** — `muted` + `playsinline` + `webkit-playsinline` で
  iOS のインライン再生を許可し、さらに最初の `touchstart` / `click` で
  `manageMedia()` を呼び直して再生をかけ直します。
- **Sound On** — 右下のトグルで動画をアンミュートします。
  ミュート状態は `soundOn` が唯一の情報源で、`manageMedia()` はシーン切替のたびに
  `vid.muted = !soundOn` を適用します。ここを無条件に `true` にすると
  Sound On が次のシーンで解除されてしまうため注意してください。
- **ビフォーアフターの色補正** — 写真は彩度を落とし（`saturate` 0.25–0.3）、
  `.ba-slider::before` のネイビーのグラデーションで青寄りに寄せて、
  ヒーローのトーンと揃えています。
- **モバイルのスライド表示** — 静止画スライド4枚は 1344×752 の 16:9 で、
  「CLEAN CULTURE」が画像に焼き込まれています。縦長画面で `cover` すると
  文字の左右が切れるため、768px 以下では `contain` でレターボックス表示にし、
  余白は同じ画像をぼかした `.kb-fill` で埋めています。
  Ken Burns のズームは切ってあります（せっかく避けたクロップに寄り戻すため）。
- **動画の明るさ** — クリップは低照度で撮られた素材なので、`--video-lift` で
  持ち上げています。この1つの数値だけで調整でき、1 なら素材そのままです。
  `brightness()` は乗算なので黒は黒のまま残り、中間調だけが開きます。
  静止画とビフォーアフターは別の階調設計なので、この補正はかけていません。
- **画像の軽量化** — スライドは PNG から JPEG（品質90・クロマサブサンプリングなし）
  に変換しました。焼き込み文字があるので 4:4:4 を維持しています。
  写真は再エンコードのみでリサイズはしていません（汚れのディテールを残すため）。
  合計 12.0MB → 4.8MB、うちヒーロー分は 5.2MB → 0.62MB です。

## ローカル確認

相対パスで画像を読むので、ファイルを直接開くのではなくサーバー経由で表示します。

```sh
python3 -m http.server 8000
# http://localhost:8000
```

## デプロイ

`main` ブランチのルートを GitHub Pages に指定すると、そのまま公開されます
（Settings → Pages → Source: Deploy from a branch → main / root）。
