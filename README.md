# 株式会社EARTHIA工業

福井・北陸の清掃会社、EARTHIA工業のコーポレートサイト。
ビルド不要の静的サイトで、Vercel から配信しています。

## 構成

```
index.html            サイト本体（HTML / CSS / JS を1ファイルに同梱）
images/               ビフォーアフター写真（ba1–6）とロゴ
                      mark-earthia.png      ナビのシンボル（白を透過）
                      logo-earthia.png      フッターのロゴ（白を透過）
                      logo-relifeworks.jpg  Re:Life Works（黒地のまま）
favicon.svg           E モノグラムのファビコン
apple-touch-icon.png  iOS ホーム画面用（180px、SVG 非対応のため別途）
vercel.json           静的配信の指定（フレームワークなし・ルートを配信）
.nojekyll             GitHub Pages に切り替えた場合の Jekyll 回避
```

ヒーローの動画8本は Higgsfield CDN（CloudFront）から直接読み込むため、
リポジトリには含まれません。

## ページの中身

- **ヒーロー** — 8本の動画を7秒ごとに切り替えるドラマ仕立てのシーケンス。
  「困っている店主のもとにプロ集団が来て、店を生まれ変わらせる」という筋立てで、
  各シーンに日本語のメッセージを1つずつ重ねています。
- **イントロ** — ステートメント。
- **事業内容** — 清掃部門 Re:Life Works と工業部門 EARTHIA工業をタブで切り替えます。
  清掃側の6サービスは料金つきで、`<details>` で開くと内容が読めます。
  料金と説明文はチラシの記載どおりです。変更する時はチラシ側も揃えてください。
  工業側は定款どおりの項目名なので説明を付けず一覧です。
  両パネルとも HTML では表示状態で置き、片方を隠すのはスクリプト側です。
  JavaScript が動かない環境でも、どちらの事業内容も消えません。
  ヒーローと実績は Re：Life Works の仕事です。
- **実績（ビフォーアフター）** — グリストラップ清掃6件。
  ハンドルをドラッグして施工前後を比較できます（マウス／タッチ対応）。
- **会社概要** — 商号・代表者・所在地・連絡先。
- **お問い合わせ** — 電話は `tel:` なのでスマホからそのまま発信できます。

## 配色

ヒーローは暗いまま、その下は明るい昼のテーマです。切り替えは `.daylight` ラッパーで、
中のセクションは同じ CSS のまま、カラートークンだけが反転します。
背景の空は `.sky`（`position:fixed`）で、CSS グラデーションを土台に写真を重ねています。
**写真が落ちてきても、落ちてこなくても空に見える**構成です。

ナビのバーも水色で、文字は濃紺です。バーは下端まで不透明にしてあります。
透けさせると、その時々のクリップの絵の上に濃紺の文字が乗って読めなくなるためです。

`#soundBtn` `.koesa-sig` `#progressBar` はヒーローの付属物なので、ヒーロー内に
`position:absolute` で置いています。`fixed` にすると明るいセクションの上に薄い色のまま
浮いてしまい、読めなくなります。

## ロゴ

EARTHIA工業のロゴは白背景を抜いた PNG です。ナビは水色、フッターは白地なので、
白のまま置くと四角い箱が浮きます。

Re:Life Works のロゴは銀と白の字で黒地に描かれているため、**明るいパネルには直接置けません**。
`.brand-band` という濃色の帯を用意し、その上に載せています。

## 実装メモ

- **文字は焼き込まない** — メッセージはすべて HTML のオーバーレイです。
  以前は映像に文字が焼き込まれていて、縦画面で両端が切れるうえ、
  オーバーレイと二重に出ていました。素材から文字を外したことで両方が解消しています。
- **クリップの読み込み** — 先頭以外は `preload="none"` で置き、`warmNext()` が
  再生順に**1本ずつ**読み込みます。次の1本は前の1本がバッファできてから始めるので、
  同時に走るダウンロードは常に1本だけです。8本を一斉に読むと回線が分割されて
  表示中のクリップが息切れし、逆に「1本先だけ・直前に読む」では遅い回線で間に合いません。
- **引き継ぎ** — 次のクリップはフェードが始まる時点で `startClip()` により再生開始します。
  クロスフェードで現れた時にはもう動いているので、最初のフレームのデコード待ちが見えません。
  250kbps に絞った状態で、引き継ぎの間隔が全シーン 0.00 秒であることを確認しています。
- **シーンの切り替え** — 固定タイマーではなく、クリップの `ended` で次に渡します。
  そのため `loop` は付けられません（loop 中は `ended` が発火しない）。
  止まったクリップで停滞しないよう、9秒のウォッチドッグを併用しています。
  これは `timeupdate` のたびに張り直すので、バッファ中で「進んではいる」クリップは
  打ち切られません。読み込みに失敗したクリップは `error` で即座に次へ送ります。
  最初のスライドには `active` が必要です。付け忘れるとシーン1が一度も表示されません。
- **モバイルの動画 autoplay** — `muted` + `playsinline` + `webkit-playsinline` で
  iOS のインライン再生を許可し、さらに最初の `touchstart` / `click` で
  `manageMedia()` を呼び直して再生をかけ直します。
- **Sound On** — 右下のトグルで動画をアンミュートします。
  ミュート状態は `soundOn` が唯一の情報源で、`manageMedia()` はシーン切替のたびに
  `vid.muted = !soundOn` を適用します。ここを無条件に `true` にすると
  Sound On が次のシーンで解除されてしまうため注意してください。
- **AI表記** — ヒーローは生成AIのイメージビデオなので、映像の上に常時注記を出し、
  フッターに正式な文言を置いています。実在のスタッフと現場に見える映像なので、
  表記が無いと誤認されます。なお**ビフォーアフター写真は実際の施工写真**です。
  ひとまとめに「フィクション」と書くと本物の実績まで作り物に見えるため、
  文言では必ず分けてください。
- **アンカーと固定ナビ** — ナビが `position:fixed` なので、リンク先の節には
  `scroll-margin-top` が要ります。無いと見出しがナビの下に潜ります。
- **日本語の折返し** — 日本語はどの文字の間でも改行されるので、狭い画面では
  語の途中で切れます。読点で区切った各句を `.clause`（inline-block）に入れ、
  句と句の間でしか改行できないようにしています。ヒーローのコピーは JS が流し込むため
  `setCopy()` が同じ処理をします。コピーを追加するときは読点を目安に区切ってください。
- **文字の太さ** — 見出しは Noto Sans JP の 900、本文寄りは 700/500 です。
  使うウェイトは Google Fonts のリクエストにも入れてください。入っていないと
  ブラウザが合成太字を作り、日本語のグリフが潰れます。
- **動画の明るさ** — `--video-lift` で持ち上げています。この1つの数値だけで調整でき、
  1 なら素材そのままです。`brightness()` は乗算なので黒は黒のまま残ります。
- **ビフォーアフターの色補正** — 写真は彩度を落とし（`saturate` 0.25–0.3）、
  `.ba-slider::before` のネイビーのグラデーションで青寄りに寄せています。
- **社名** — ロゴは英語の `EARTHIA`、その下に正式名称の `株式会社EARTHIA工業`。
  英語の見た目を保ちつつ、取引先が実在を確認できるようにしています。

## デプロイ

`main` への push で Vercel が自動デプロイします。

コミットのメールアドレスは GitHub アカウントに紐付くものを使ってください。
紐付かないアドレスのコミットは Vercel が "Deployment was blocked" で弾きます。
